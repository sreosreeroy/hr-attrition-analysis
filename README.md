# HR Attrition Analysis
HR Attrition Analysis using Excel and Power BI to understand employee attrition patterns and workforce trends.
## Project Overview
This project analyzes employee data to understand attrition patterns and identify workforce factors associated with employee turnover. Excel and  Power BI were used for data analysis, visualization, and dashboard development.
## Objective
- Analyze employee attrition patterns.
- Examine employee demographics and job-related characteristics.
- Identify factors associated with employee attrition.
- Analyze workforce trends using key HR metrics.
- Present findings through an interactive Power BI dashboard.
   ## Tools & Technologies
  - Microsoft Excel
  - Power BI
  - Github
 ## Data Preparation & Analysis
 The HR dataset was prepared and analyzed using Excel. Relevant employee and job-related fields were reviewed and organized before creating the Power BI dashboard.
 ## Power BI Dashboard
 An interactive Power BI dashboard was created to provide an overview of Superstore sales and profitability .
 The dashboard presents key HR metrics and visualizations covering employee demographics, job characteristics, departments, income,      experience, and attrition patterns.
 ## Key Business Insights
 - Attrition patterns can vary across employee and job characteristics.
 - Department and job-related factors provide useful context when analyzing employee attrition.
 - Employee compensation and experience can be compared across attrition groups.
 - Demographic and workforce characteristics can help identify differences in attrition patterns.
 - The dashboard provides a consolidated view of employee attrition and workforce trends.
